# Frame By Plane 7.1.18 LTS

Frame By Plane 7.1.18 is a Blender 5.2 LTS stability update for image-sequence, Grease Pencil and 2.5D animation workflows.

## Highlights

- Fixed persistent ownership for all 27 native Grease Pencil effect backends.
- Prevented duplicate effects caused by Blender 5.2 rejecting custom properties on Shader Effects and modifiers.
- Restored add, remove, reorder, reset and duplicate-repair behavior.
- Added Expand All and Collapse All controls to the Grease Pencil Effect Stack.
- Fixed Compositor Safe Repair snapshots for color, vector and rotation socket values.
- Preserved artist-authored, untagged modifiers, Shader Effects, compositor nodes and links.
- Fixed Bookmark Color Tag swatches so every color name matches the menu icon and Scrub Bar color.

## Blender 5.2 validation

- Blender 5.2.0 LTS extension validation: PASS.
- Native background suite: PASS.
- Interactive 300-redraw UI stress suite: PASS.
- Register/unregister, in-place reload, scheduler teardown, save/reopen and tiny render: PASS.
- Repeated normalized builds produce identical SHA-256 hashes.

## Compatibility

- Requires Blender 5.2.x LTS.
- No project schema migration is required.
- Use the platform-specific ZIP for Windows, Intel/Apple Silicon macOS or Linux; do not install GitHub's generated source archive.
- The Intel macOS ZIP is structurally validated; Blender's official 5.2.0 checksum list currently contains no Intel runtime image for the native smoke matrix.
