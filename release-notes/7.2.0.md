# Frame By Plane 7.2.0 — Pre-release

Frame By Plane 7.2 is a Blender 5.2 LTS pre-release for Grease Pencil, image-sequence and frame-by-frame animation, storyboarding, layered PSD/Procreate artwork, 2.5D multiplane scenes, compositing and non-destructive effects.

This candidate combines the complete 7.1.19 stability branch with the later Grease Pencil color workflow. It is published as a pre-release so production artists can validate the new Tool Header integration before the stable 7.2 promotion.

## Dual Grease Pencil Stroke and Fill colors

- Adds separate **Stroke** and **Fill** color selectors to Blender 5.2 Grease Pencil Draw, Vertex Paint and Edit modes.
- Keeps distinct colors in **Stroke**, **Fill** and **Both** drawing modes instead of collapsing them into one active brush color.
- Uses `X` to swap Stroke and Fill and `Shift+X` to sample only the Stroke color continuously under the cursor.
- Shows compact mixed-color swatches for multi-color Edit Mode selections and edits selected point and curve-fill colors independently.
- Adds **Close Gap** between Stroke/Fill/Both and Caps Type in the Draw Tool Header. `G` toggles it only in Draw Mode, leaving Blender's Edit Mode Grab shortcut untouched.
- Places Pin Mode next to Material / Color Attribute and restores every native UI function, timer, handler and keymap on add-on disable.

## Undo and drawing reliability

- Gives color swap, Stroke sampling, Close Gap and Edit Mode color changes dedicated Undo steps.
- Preserves the expected `X → draw → Ctrl+Z → Ctrl+Z` order: first remove the new stroke, then undo the color swap.
- Resets Draw tracking after Undo/Redo so the next Both-mode stroke still receives its separate Fill color and cyclic state.
- Keeps GP material and native effect settings read-only in Edit Mode where Blender 5.2 cannot restore those Object/Material changes safely; point colors and geometry remain editable.

## Camera, Properties and compositor UX

- Separates ten landscape-first aspect shapes from SD, HD, 2K, 4K, 8K and Custom resolution.
- Always exposes Width and Height pixels with a linked/unlinked ratio control, responsive wrapping, orientation swap and saveable Camera Format Presets.
- Moves selected Frame By Plane layer controls into Object Data Properties with an Image-style panel and mirrors Layers, Grease Pencil and Layer Settings under one clean Tool-tab root.
- Makes the managed compositor explicitly opt-in for rendering. Artists can build and inspect Frame By Plane nodes without changing F12 output; artist compositor graphs and prior render state are preserved.

## Effects, timeline and workflow polish

- Uses selectable image-plane and Grease Pencil effect lists with compact add/remove/reorder/reset controls and grouped icon menus.
- Revalidates all 133 effect paths: 6 Base, 79 Shader, 21 Geometry Nodes and 27 native Grease Pencil effects.
- Preserves artist-created modifiers and fixes Generic Mesh Preview ownership, dynamic inputs and rollback.
- Backports compact Blender playback controls and adds synchronized time controls to Timeline, Dope Sheet, Graph Editor, NLA and Sequencer.
- Simplifies Shift+A and Scrub Bar menus, adds adaptive None bookmark tags, fixes Grey, and migrates legacy White/Blue tags.
- Keeps import dialogs safe across New/Open/Reload and Animation/Storyboard template switches, including stale Scene RNA wrappers.

## Validation in Blender 5.2

- Complete background regression suite: pass.
- Interactive Viewport/header, Preferences, two-window and repeated Undo/Redo suite: pass.
- Focused 7.2 GP color, Close Gap, paint/edit Undo, compositor opt-in, Properties panel and three-cycle lifecycle gate: pass.
- Five deterministic platform packages validated for Windows x64/ARM64, macOS Intel/Apple Silicon and Linux x64.
- Windows x64 package installed into an isolated Blender profile and retested before publication.

Requires Blender 5.2.x LTS. Install the ZIP matching your operating system and CPU; do not install GitHub's automatically generated source archive.
