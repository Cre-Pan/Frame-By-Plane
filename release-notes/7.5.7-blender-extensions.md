# 🎞️ Frame By Plane — 7.5.7

A Grease Pencil, Scrub Bar and Add Plane update for Blender 5.2 LTS.

- ⏱️ **Magnetic Scrub Bar:** release `<` and the playhead snaps back to where you started. Exact on the bar, faster further away. Pin it from the Viewport header.
- 🗂️ **Scrub Bar menu:** collapsible sections and a live Length slider.
- 🎨 **Every selected color:** each Stroke and Fill color as its own swatch in Edit Mode, with Replace All and per-stroke Invert.
- 🖌️ **Material in Edit Mode.**
- ➕ **One Add Plane dialog** for Image, Video, Color, Gradient and Holdout planes.
- 📁 **Project folders:** generated media goes into an `assets` folder next to your `.blend`; presets move to the extension's user folder.
- 🛠️ Stability fixes.

**Removed:** the Grease Pencil effect list (use Blender's Modifiers and Visual Effects panels), Draw on Canvas, Ink Over Image, Create Missing / Current GP Drawings and Limited Loop Blocks. Files that used them still open.

> Requires **Blender 5.2.x LTS**.
