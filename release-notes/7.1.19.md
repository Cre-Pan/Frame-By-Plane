# Frame By Plane 7.1.19 LTS

Frame By Plane 7.1.19 is a Blender 5.2 LTS stability and UX update for image sequences, Grease Pencil animation, layered PSD and Procreate artwork, 2.5D multiplane scenes, compositing and non-destructive effects.

## Bookmark Color Tags

- Replaced fixed White with adaptive **None**, using white or black to contrast with the Viewport background just like the Timeline ink.
- Removed Blue, matched Grey to Blender's `STRIP_COLOR_09` swatch and retained the remaining color tags.
- Migrates legacy White tags to None and legacy Blue tags to Cyan automatically.
- Added regression coverage for adaptive color, palette icons and legacy identifier migration.

## Workflow compatibility

- Simplified **Shift+A > Frame By Plane** and moved **Color Plane from Hex** into **More...**.
- Removed **Import a Folder** and **Import Folder Path from Clipboard** from that secondary menu; existing project data and the reimport workflow remain compatible.
- Kept the Frame By Plane 7.1 project schema unchanged; no manual migration is required.

## Blender 5.2 stability

- Revalidates queued work immediately before execution, including Undo/load epoch, render/modal guards and deadlines changed by earlier callbacks in the same batch.
- Distinguishes partial layer mirrors from complete scene-index caches so recovery includes all owned rigs/planes. Reuses validated empty-scene results instead of scanning unrelated objects on every request.
- Precomputes camera aspect shape labels to reduce repeated parsing during UI redraw.
- Separates a 10-shape camera aspect dropdown from SD, HD, 2K, 4K, 8K and Custom resolution. Selecting a shape defaults to landscape, including 4:5 as horizontal 5:4; an icon-only Swap Dimensions button switches orientation. Resolution changes preserve that orientation.
- Uses Blender's Image Background and Swap Dimensions icons, with separate unaligned action buttons. Width and Height pixel fields are always available beside Resolution, or on a second row in narrow panels.
- Links pixel dimensions by default: editing either side preserves the aspect ratio. Unlinked edits change only one side and mark the aspect Custom. Rejects linked dimensions outside Blender's limits without partially changing output.
- Adds a compact Camera Format Presets popover to save, apply and remove formats in the blend file, including orientation and linked state, with Undo support. Render percentage and pixel-aspect controls remain in Output Properties.
- Keeps native render dimensions authoritative in the new camera controls, including after Undo/Redo and edits in Output Properties; preserves legacy combined presets in existing files.
- Makes GP material and native effect controls read-only in Edit Mode, with an explicit Object Mode action. Blender 5.2's edit history does not restore Material/Object property edits; point-color and geometry editing remain available in Edit Mode.
- Keeps Blender's native Viewport header draw untouched, places Scrub Bar controls in its centered transform or Grease Pencil lane and uses the official append/remove callback as the fallback for remaining modes without either lane.
- Moves selected-layer settings to Object Data Properties with an Image icon, keeps the layer stacks in Tool and restores the optional Frame By Plane N-Panel roots.
- Makes custom camera projection, lens/scale, clipping and aspect controls update the active camera immediately.
- Differentiates Interface preference icons and uses Monkey for Updates and Support.
- Removed Interaction Info and its saved preference, Add Bookmark and the obsolete transparent-viewport label from the Scrub Bar popover; Add Bookmark remains on right-click and A.
- Reordered the context menu to Add Bookmark, Select/Deselect All, active Keyframe Type, Mirror, Duplicate (Shift+D) and Delete.
- Includes persistent ownership for all 27 native Grease Pencil effect backends.
- Prevents unmanaged duplicate Shader Effects and Grease Pencil modifiers.
- Presents native Grease Pencil effects in a selectable list with add, remove, reorder, reset and duplicate-repair actions.
- Uses an icon-based add menu divided into Stylize, Light & Edge, Warp, Stroke, Motion & Build, Utility and Surface.
- Shows only the selected effect's controls below the stack for a cleaner, plane-effects-style workflow.
- Keeps Compositor Safe Repair fail-closed while supporting Blender color, vector, rotation and matrix values.
- Fixes the canonical Felt Fuzz Seed/Alpha Mask contract while preserving saved `Base Seed` values from 7.1 projects.
- Releases Grease Pencil raster-mask buffers during reload, file replacement and add-on teardown.
- Removes proven orphan code and unused imports, including the retired Tool Sequence path, without changing saved RNA names, effect IDs or public 7.1.x aliases.
- Expands native Grease Pencil controls for Rim, Shadow, Blur, Glow and Outline.
- Corrects Glow reset/default values for Blender 5.2 and raises Rim/Shadow sampling quality without changing existing saved effects.
- Uses short same-directory temporary manifest names to avoid Windows `MAX_PATH` failures during rollback-safe rename operations.
- Keeps Single Plane and the other file-browser imports safe across Animation/Storyboard template changes; a partially reloaded add-on now reports a clear restart/re-enable action instead of raising a missing `fbp_project_path` traceback.
- Handles stale Scene wrappers retained by an already-open import dialog during New/Open/Reload without exposing a Python `ReferenceError`.
- Uses Blender 5.2's valid Geometry Nodes icon throughout the expanded Grease Pencil Compatibility Matrix.

## Timeline and synchronized editors

- Backports Blender PR 162412's compact playback row to Blender 5.2 LTS.
- Lets artists configure endpoint, keyframe and delta jump buttons from one popover.
- Adds time synchronization popovers to Timeline, Dope Sheet, Graph Editor, NLA and Sequencer.
- Maps Scene Strip frames in both directions without forcing the current editor to switch Scene.

## Packaging and support

- Requires Blender 5.2.x LTS.
- Provides separate ZIP packages for Windows x64, Windows ARM64, macOS Intel, macOS Apple Silicon and Linux x64.
- Packages include the matching Pillow and psd-tools wheels for PSD, PSB, Procreate and image-processing workflows.
- Release tooling rejects version drift across the manifest, builder, publisher, notes and native test matrix.
- ZIP metadata is normalized so identical source produces identical SHA-256 hashes.
