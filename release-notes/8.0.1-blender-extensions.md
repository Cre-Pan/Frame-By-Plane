# 🎞️ Frame By Plane — 8.0.1

Frame By Plane 8 LTS for Blender 5.2 LTS.

**New in 8.0.1**
- 🧱 **Frame Stack:** earlier frames stacked in depth as a solid of time.
- 🧶 **Knit & Crochet:** the image rebuilt as yarn stitches.
- 🖨️ **Riso Print**, 🖌️ **Oil Paint** and 🔲 **Edge Distance Mask**.
- ➕ **Fewer popups:** plane settings in the file browser sidebar and the Adjust Last Operation panel.
- 🔦 **Image Projector:** sharp by default, whole image in the cone, sequence and layer timing fixes.

**Also in 8 LTS**
- 🎭 Editable Grease Pencil Mask, ✂️ Split into Multiple Planes, 💡 SOLO badge, 🎓 new Live Tutorial.
- ⏱️ Magnetic Scrub Bar, 🌀 Deform Plane poses, 🎯 on-plane handles for any image shape.
- 🧩 Compositor: Off really turns it off. ⚡ Faster effect stacks. 🌍 Six languages.

**Removed:** the GP effect list, Draw on Canvas, Ink Over Image and Limited Loop Blocks. Old files still open.

> Requires **Blender 5.2.x LTS**.
