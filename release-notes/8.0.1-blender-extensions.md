# 🎞️ Frame By Plane 8.0.1 — 8 LTS

All changes since 7.2.1. Requires **Blender 5.2 LTS**.

### ✨ New
- 🎨 **5 new effects:** Frame Stack, Knit & Crochet, Riso Print, Oil Paint, Edge Distance Mask.
- ➕ **Fewer popups:** settings in the file browser sidebar and Adjust Last Operation.
- 🎭 **Grease Pencil Mask** you can edit, with proper Undo.
- ✂️ **Split into Multiple Planes**, 💡 **SOLO badge**, 🧪 **Apply Effects**.
- ⏱️ **Magnetic Scrub Bar:** hold `<` to scrub, in the Timeline too.
- 🌀 **Deform Plane poses** as keyframeable sliders.
- 🎓 **New Live Tutorial** with a Frame by Frame guide.
- 🌍 **Six languages:** IT, ES, FR, DE, ZH, JA.

### 🛠️ Better
- ⚡ Faster effect stacks, many fixes.
- 🧩 Compositor: Off really turns it off.
- 🔦 Sharper Image Projector.
- 📁 Generated media saved in an `assets` folder by the `.blend`.

### 🗑️ Removed
GP effect list, Draw on Canvas, Ink Over Image, Create Missing Drawings and Limited Loop Blocks. Old files still open.
