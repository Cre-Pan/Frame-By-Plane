# 🎞️ Frame By Plane 8.1.0 — 8 LTS

All changes since 7.2.1. Requires **Blender 5.2 LTS**.

### ✨ New in 8.1
- 🌀 **Lattice puppet rig:** Grid handles, Corner Pin, Bones with IK, Puppet Pins.
- 🎨 **An icon for every effect**, tidier add menus.
- 🟩 **Color Key** absorbs Chroma Key, with Despill.
- 🖨️ **Riso Print:** Drift Angle, Print Rotation, Seed, Animate.
- 🥧 Tidier **Z Pie**, shorter tooltips.

### ✨ New in 8.0
- 🎨 **5 new effects:** Frame Stack, Knit & Crochet, Riso Print, Oil Paint, Edge Distance Mask.
- ➕ **Fewer popups**, 🎭 editable **Grease Pencil Mask**.
- ✂️ **Split into Multiple Planes**, 💡 **SOLO badge**, 🧪 **Apply Effects**.
- ⏱️ **Magnetic Scrub Bar**, 🎓 new **Live Tutorial**.
- 🌍 **Six languages:** IT, ES, FR, DE, ZH, JA.

### 🛠️ Better
- ⚡ Faster effect stacks, many effect fixes.
- 🧩 Compositor: Off really turns it off. 🔦 Sharper Image Projector.

### 🗑️ Removed
GP effect list, Draw on Canvas, Ink Over Image, Create Missing Drawings and Limited Loop Blocks. Old files still open.
