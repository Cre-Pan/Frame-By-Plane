# 🎞️ Frame By Plane — 8.0.0

A big workflow and reliability update for Blender 5.2 LTS.

## ✨ Highlights

- 🌀 **Deform Plane poses:** Sway, Arch, Squash, Taper, Bulge, Wave, Flag, Curl and more as animatable sliders.
- 🎯 **On-plane handles** now match Gradient, Radial Gradient and Tilt-Shift on any image shape.
- 🧩 **Compositor:** Off really turns it off, and F12 never changes until you opt in.
- ⚡ **Faster effect stacks**, especially when Image and Mesh effects are mixed.
- 🛠️ **Many effect-stack fixes:** Hide in Render, duplicates, variants, groups, masks, copy/paste and presets.
- ✏️ Includes the Grease Pencil Gap Off/On icons and color-control polish from 7.2.1.

> Requires **Blender 5.2.x LTS**.
