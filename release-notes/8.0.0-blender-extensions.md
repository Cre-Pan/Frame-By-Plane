# 🎞️ Frame By Plane — 8.0.0

Frame By Plane 8 LTS for Blender 5.2 LTS.

- 🎭 **Editable Grease Pencil Mask:** Edit button, show/hide eye, proper Undo, much faster.
- ✂️ **Split into Multiple Planes:** one plane per frame, position kept.
- 💡 **SOLO badge** in the Viewport.
- 🎓 **New Live Tutorial** with a Frame by Frame guide.
- ⏱️ **Magnetic Scrub Bar:** release `<` and the playhead snaps back.
- 🎨 **Every selected color** as a swatch in Edit Mode.
- ➕ **One Add Plane dialog** for every plane type.
- 🌍 **Six languages.**
- 📁 Generated media goes into an `assets` folder next to your `.blend`.

**Removed:** the Grease Pencil effect list, Draw on Canvas, Ink Over Image, Create Missing / Current GP Drawings and Limited Loop Blocks. Files that used them still open.

> Requires **Blender 5.2.x LTS**.
