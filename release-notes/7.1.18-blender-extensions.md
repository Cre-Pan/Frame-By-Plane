# Frame By Plane 7.1.18 LTS

Blender 5.2 LTS stability update for image sequences, Grease Pencil and 2.5D animation.

## Highlights

- Fixed persistent ownership for all 27 native Grease Pencil effect backends.
- Restored add, remove, reorder, reset, duplicate repair and saved inline state.
- Added Expand All and Collapse All to the Grease Pencil Effect Stack.
- Fixed Safe Repair snapshots for Blender color, vector, rotation and matrix values.
- Preserved untagged artist effects, compositor nodes and links.
- Fixed Bookmark Color Tag swatches so names and colors agree.
- Passed Blender 5.2.0 background, interactive 300-redraw, isolated install, save/reopen and five-platform archive validation.
- Normalized builds produce reproducible SHA-256 hashes.

Requires Blender 5.2.x LTS. No migration required. Install the platform-specific ZIP. The Intel macOS ZIP is structurally validated because Blender's official 5.2.0 checksum list currently contains no Intel runtime image.
