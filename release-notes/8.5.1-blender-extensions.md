🎞️ Frame By Plane - 8.5.1 LTS
All changes since 8.0.1. Requires Blender 5.2 LTS or 5.3.
✨ New

* 🌀 Lattice Puppet Rig: Pins, Bones with IK, Corner Pin, Grid; all in Pose Mode.
* 🔲 New Transform Box: move, scale and rotate around the anchor point.
* 🧩 Native Modifiers panel: every effect is a modifier you can edit.
* 💥 Broken Glass shatter, 🎨 Replace Color, 🟩 Color Key with Despill.
* 🎯 Minimal viewport controls, ✂️ Crop / Extend rig.
* 🖼️ Plane Material panel in Properties > Material.
* 🪞 Flip Canvas in the Z Pie, 📝 Markdown node notes (5.3).

🛠️ Better

* ▶️ Smoother playback with sequences and effects.
* 🧱 Frame Stack rewritten: follows playback, far lighter.
* 👁️ Rigs readable from every view, Top and Side too.
* 🎨 Color Plane: new colour in renders, keyframable Opacity.
* 🖨️ Riso Print: Drift Angle, Print Rotation, real Seed.
* 🛡️ Many stability fixes.
* 🧭 One package for Blender 5.2 LTS and 5.3.

🗑️ Removed
Chroma Key (now in Color Key) and the Modifiers tab pin. Old files still open.
