# Frame By Plane 7.2

- Dual Grease Pencil Colors: independent Stroke/Fill in Draw, Vertex Paint and Edit modes, including Both mode.
- Edit Mode Color Control: recolor selected strokes/fills and see mixed-color swatches.
- X swaps colors; Shift+X samples Stroke. Close Gap has a Draw-only G shortcut.
- Smarter Camera Settings: aspect presets, orientation swap, linked Width/Height, SD-8K/Custom resolution and saved formats.
- Better Undo/Redo handling for GP colors, drawing and Close Gap.
- Consistent effect lists and grouped icon menus for planes and Grease Pencil.
- Cleaner Scrub Bar menus, adaptive bookmark tags and synchronized time editors.
- Compositor rendering is opt-in, preserving artist graphs and render settings.
- Safer imports and template changes; What's New waits until Preferences is closed or left after an update.
- Updated artwork, UI polish and reduced redundant splash loading.

Requires Blender 5.2.x LTS. Choose the ZIP matching your OS and CPU.
