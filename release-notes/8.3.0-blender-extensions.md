# 🎞️ Frame By Plane 8.3.0

All changes since 7.2.1. Requires **Blender 5.3**.

### ✨ New in 8.3
- ✏️ **Lasso** and **Carver** in the Z Pie, 🪞 **Flip Canvas**.
- 📝 Markdown notes in node trees.
- 🛠️ Fixed Copy to Selected and Extend after Crop.

### ✨ New in 8.2
- 🌀 **Lattice rig:** Grid handles, Corner Pin, Bones, Pins.
- 🎯 **Minimal controls**, 🎨 an **icon per effect**.
- 🧩 Mesh effects in **Add Modifier**.
- 💥 **Broken Glass**, 🎨 **Replace Color**.
- 🧱 **Frame Stack** follows playback.
- 🟩 **Color Key** absorbs Chroma Key, with Despill.

### ✨ New in 8.0
- 🎨 **5 new effects** incl. Frame Stack and Knit & Crochet.
- ➕ **Fewer popups**, 🎭 editable **Grease Pencil Mask**.
- ⏱️ **Magnetic Scrub Bar**, 🎓 new **Live Tutorial**.
- 🌍 **Six languages**.

### 🛠️ Better
- ⚡ Faster effect stacks, many effect fixes.
- 🧩 Compositor: Off really turns it off. 🔦 Sharper Image Projector.
