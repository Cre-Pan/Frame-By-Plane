# 🎞️ Frame By Plane — 7.2.1

A small Grease Pencil workflow update for Blender 5.2 LTS.

## ✨ What's improved

- ✏️ **Gap Off / On:** new custom icons with two connected buttons, separated from the other controls.
- 🎨 **Cleaner color controls:** more space after Pin Mode and a visible background for Swap Colors, including Edit Mode.
- ⏱️ **Consistent Scrub Bar:** always first in the centered Viewport controls across all six Grease Pencil modes.
- 🛠️ **Edit Mode fix:** Gap Off correctly opens selected curves even when the selection contains both open and closed strokes.
- ↩️ **Familiar shortcuts:** `G` still toggles Close Gap in Draw Mode; clicking an active Gap option never flips it.

> Requires **Blender 5.2.x LTS**.
